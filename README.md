# Python Web Scraping Project

This project extracts product data from multiple web pages using Python and exports the collected data into CSV and Excel files.

## Features

- Scrapes product data from multiple pages
- Extracts product name, current price, old price, and product URL
- Collects up to 1000 product records
- Exports results to CSV and Excel
- Uses a structured Pandas DataFrame

## Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas
- Regex
- Jupyter Notebook
- CSV
- Excel

## Output

The project generates:

- `sheffield_raw_data.csv`
- `sheffield_raw_data.xlsx`
